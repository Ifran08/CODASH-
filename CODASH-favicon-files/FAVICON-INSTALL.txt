CODASH FAVICON INSTALLATION

1. Copy all five image files into the root folder of your GitHub repository:
   - favicon.ico
   - favicon-16x16.png
   - favicon-32x32.png
   - android-chrome-512x512.png
   - apple-touch-icon.png

2. Replace your existing main.js with the included main.js.

The favicon will then be applied automatically to every page that loads main.js.

Alternatively, you can add this directly inside every HTML <head>:
<link rel="icon" type="image/x-icon" href="favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png">
<link rel="apple-touch-icon" href="apple-touch-icon.png">

Do not use the previously generated SVG favicon. These files are the favicon assets you provided.
